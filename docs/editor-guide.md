# Editing the website — a guide for the parish

This site is built so that day-to-day updates can be made without touching any code.

## Signing in

1. Go to `https://your-domain.org.uk/studio`.
2. Sign in with the account you have been given.

You will see a list of content types down the left-hand side.

## Common jobs

### Add a news post

1. Choose **News post** → **Create new**.
2. Give it a **Title**. The web address fills in automatically.
3. Add a **Date** and a short **Summary**.
4. Write the **Body**. Use the toolbar for headings, links and bullet lists.
5. Optionally add a **Cover image** — you **must** add alternative text describing the photo.
6. Click **Publish**. It appears on the site within a minute or two.

### Add or change an event

1. Choose **Event** → **Create new** (or open an existing one).
2. Add the **Title**, **Summary** and **Details**.
3. Under **When it happens**, set the day (for example “Every Thursday”) and the time.
4. Add **Tags** such as “Refreshments” or “Family friendly”.
5. **Publish**.

### Change a service time

1. Choose **Service time** and open the one you need.
2. Update the **Time** or **When (pattern)**.
3. **Publish**. The home page and Services page both update.

### Add a photo to the gallery

1. Choose **Gallery photo** → **Create new**.
2. Upload the **Photo**.
3. Add **Alternative text** — describe what is in the photo, for people who cannot see it.
4. Set an **Order** number so it appears where you want.

## Alternative text — please do not skip this

Alternative text is how someone using a screen reader knows what a photo shows. Write a short,
plain description: “The choir singing at the Christmas service”, not “IMG_2043.jpg”.
Every image field **requires** this — you will not be able to publish without it.

## If something goes wrong

Nothing you do here can break the live site permanently — you can always edit or delete a post
and publish again. If you get stuck, contact whoever set the site up.
