# Alt text review

The photographs in `public/images/church/` were downloaded from the church's ACNY media library.
Their alt text in `src/lib/content/seed.ts` is **provisional** and must be reviewed — the images
could not be inspected when the site was first built.

Some are likely to be generic (“St Simon and St Jude Parish Church”), which is not good enough
for an accessibility statement that claims WCAG 2.2 AA.

## What to do

For each photo below, look at the image and replace the alt text with a short, specific
description of what is actually shown.

| File | Current alt text |
|---|---|
| `church-01.jpg` | St Simon and St Jude Parish Church, Thurcroft |
| `church-02.jpg` | Inside St Simon and St Jude Parish Church |
| `church-03.jpg` | The church building and grounds in Thurcroft |
| `church-04.jpg` | A view of St Simon and St Jude Parish Church |
| `church-05.jpg` | The congregation and church interior |
| `church-06.png` | St Simon and St Jude Parish Church |
| `old-church-building.jpg` | The old St Simon and St Jude church building, which later became the Church Hall |
| `walls-fund-flyer.jpg` | Fundraising flyer for the Thurcroft Parish Church walls project |

## Guidance

- Describe the content and purpose, not the file.
- Keep it to roughly 125 characters where possible.
- If a photo is purely decorative, say so and mark it decorative rather than describing it.
- Do not start with “Image of…” or “Photo of…”.
